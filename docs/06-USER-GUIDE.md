# User Guide

## Sign in

Use a demo account from the main README and the demo password. The navigation changes according to role. Accounts lock after five failed attempts; ask the system administrator to unlock a demo account.

## Patient

Register, choose a practitioner and available slot, confirm the demo invoice, then use the dashboard to review appointments, results and plans. Mark meals complete, add water intake, send only non-urgent questions, and submit feedback after a completed consultation.

## Doctor or medical coordinator

Open the assigned patient, review earlier results and record the current measurements. The system compares them with demonstration thresholds. Complete consultation notes and create a follow-up recommendation when appropriate.

## Dietitian

Review the health-alert queue, compare current and previous measurements, create a plan with targets/exclusions/meals, publish it and monitor adherence. Use messages for non-urgent guidance.

## Reception and finance

Reception can create, move and cancel bookings while viewing the central schedule. Finance can inspect invoices and record a safe demo payment status. Never type a real card number or CVV.

## Administrator and management

Administrators manage roles and locked accounts and review audit activity. Managers filter operational and satisfaction reports and assign complaint follow-up. Exported figures represent synthetic demo data.
